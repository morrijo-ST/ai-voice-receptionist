# AI Voice Receptionist

A public-safe conversational operations demo for inbound call handling, intent classification, appointment routing, escalation, and call summaries.

## Demonstrates
- intent detection
- appointment / callback workflows
- escalation rules
- CRM-ready structured outputs
- call summaries and dispositioning
- human handoff controls

No live telephony provider or customer data is used.

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```
